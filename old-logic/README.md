# Archived website material

This directory preserves website-only planning and content notes moved out of
the original `lax` repository after the standalone website became the source
of truth.

Nothing here is loaded by the generator, included in the rendered site, or
used by deployment workflows.

- `website-plan.md` records the implemented 2026-07-27/28 design passes and
  the original claim-page brief.
- `original-content-readme.md` records how the first landing and contributing
  Markdown files were wired into the original monorepo package.

Current website content lives in `content/`; current rendering code and
assets live in `src/sitegen/` and `assets/site/`.
