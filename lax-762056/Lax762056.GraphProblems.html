      Definition

      Independent Set asks whether a graph has an independent set of size at least kkk. Max Cut asks whether it has a cut with at least kkk crossing edges.

      A graph problem is NP-hard on a class C\mathcal CC if every language in NP has a polynomial-time many-one reduction to the problem whose output graph always belongs to C\mathcal CC. Instances use the adjacency-matrix encoding.
