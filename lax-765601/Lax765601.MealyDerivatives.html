      Theorem

      A string-to-string function is computed by a Mealy machine if and only if (1) it has finitely many derivatives, (2) it is letter-to-letter, and (3) its nnn-th output letter depends only on the first nnn input letters (Lemma A.2.10 of Transducers). From a machine, the derivative f(w_)f(w\_)f(w_) is determined by the state reached after reading www, so there are finitely many. Conversely, the minimal machine of fff has the derivatives as its states, the derivative of the empty string as initial state, and the transitions

      f(w_)→a / last letter of f(wa)f(wa_),f(w\_) \xrightarrow{a\,/\,\text{last letter of } f(wa)} f(wa\_),f(w_)a/last letter of f(wa)​f(wa_),

      which are well defined because the output letter and the target depend only on the derivative f(w_)f(w\_)f(w_) and not on www.
