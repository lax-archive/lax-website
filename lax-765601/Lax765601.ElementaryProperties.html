      Definition

      Three elementary properties of a string-to-string function f:A∗→B∗f : A^* \to B^*f:A∗→B∗ that the characterisation theorems of the book are stated with.

      • fff is prefix preserving if w⊑vw \sqsubseteq vw⊑v implies f(w)⊑f(v)f(w) \sqsubseteq f(v)f(w)⊑f(v), where ⊑\sqsubseteq⊑ is the prefix order on strings.
      • fff is length preserving, or letter-to-letter, if ∣f(w)∣=∣w∣|f(w)| = |w|∣f(w)∣=∣w∣ for every input string www.
      • fff is prefix determined if the first nnn output letters depend only on the first nnn input letters: input strings that agree on their first nnn letters have outputs that agree on their first nnn letters.

      For a letter-to-letter function, being prefix determined says exactly that the nnn-th output letter depends only on the first nnn input letters, which is condition (3) of the Myhill–Nerode lemma for Mealy machines (Lemma A.2.10), and it is the determinism condition of Theorem B.2.7; prefix preservation and length preservation together are the shape of the machine-independent characterisation of Mealy machines (Theorem B.4.1).

      26# Formalization notes

      28`<+:` is mathlib's prefix relation on lists. The three definitions quantify over
      29all strings of the input alphabet and carry no finiteness hypothesis.

      32namespace Lax765601.ElementaryProperties
      33
      34/-- `f` is prefix preserving: `w ⊑ v` implies `f w ⊑ f v`. -/
      35def PrefixPreserving {A B : Type} (f : List A → List B) : Prop :=
      36 ∀ w v : List A, w <+: v → f w <+: f v
      37
      38/-- `f` is length preserving, i.e. letter-to-letter: the output has the length of
      39the input. -/
      40def LengthPreserving {A B : Type} (f : List A → List B) : Prop :=
      41 ∀ w : List A, (f w).length = w.length
      42
      43/-- `f` is prefix determined: the first `n` output letters depend only on the
      44first `n` input letters. -/
      45def PrefixDetermined {A B : Type} (f : List A → List B) : Prop :=
      46 ∀ (w v : List A) (n : ℕ), w.take n = v.take n → (f w).take n = (f v).take n
      47
