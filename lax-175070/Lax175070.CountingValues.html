      Natural Language Statement

      Lemma

      The decision version of a counting problem by a property of numbers holds on a structure exactly when its count has the property. The number of models of an instance with a selected variable in which the selected variables have a given value is invariant under isomorphism, so it is the value of #SelSATb_bb​; SelMajSAT and SelEqSAT hold exactly when these counts compare as they ask.

      41axiom decide_iff :
      42 ∀ {L : Language.{0, 0}} [L.IsRelational] (R : ℕ → Prop) (C : CountingProblem L)

      45/-- The number of models with the selected variables at `b` is isomorphism-invariant. -/
      46axiom sharpSelSat_count_iso :
      47 ∀ (b : Bool) {A B : Type} [satSel.Structure A] [satSel.Structure B],
      48 (A ≃[satSel] B) → Nat.card {ν : A → Prop // SelModel A b ν} = Nat.card {ν : B → Prop //
      49 SelModel B b ν}

      51/-- The value of #SelSAT is the number it counts. -/
