      Definition

      A binary language belongs to L\mathrm{L}L if a deterministic Turing machine decides membership using O(log⁡n)O(\log n)O(logn) work space and a separate read-only input tape. Precisely, some positive constant ccc bounds work space by c⌊log⁡2(n+2)⌋c\lfloor\log_2(n+2)\rfloorc⌊log2​(n+2)⌋ on every input of length nnn.
