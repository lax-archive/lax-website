      Abstract

      We prove that binary-encoded CNF satisfiability is NP-complete under polynomial many-one reductions. The proof implements the SAT verifier and the reduction from bounded computations through Boolean circuits and gate clauses. It includes machine correctness and polynomial running-time bounds, using NP from lax-434930 and the machine model of lax-554803.
