Theorem

If two vertices have the same closed neighborhood, they represent the same radius-one concept and have interchangeable label behavior across all such concepts. Replacing the teaching set of one twin by a copy of the other's preserves positivity, the no-clash property, the width bound, and nonemptiness.

5title: Copying a teaching set across closed-ball twins

8If two vertices have the same closed neighborhood, they represent the same
9radius-one concept and have interchangeable label behavior across all such
10concepts. Replacing the teaching set of one twin by a copy of the other's
11preserves positivity, the no-clash property, the width bound, and nonemptiness.
12-/

14namespace Lax16.TwinReduction
15
16open Lax16.TeachingMaps
17
18universe u
19
20/-- Replace the teaching set at `target` by the set at `source`. -/
21noncomputable def copyTeachingSet {V : Type u} {k : ℕ} (T : TeachingMap V k)
22 (source target : V) : TeachingMap V k := by
23 classical
24 exact fun v => if v = target then T source else T v
25
26/-- Copying a teaching set between radius-one twins preserves validity. -/
27axiom copy_twin_preserves {V : Type u} {G : SimpleGraph V} {d : ℕ}
28 {T : TeachingMap V 1} {source target : V}
29 (htwins : closedBall G 1 source = closedBall G 1 target)
30 (hpositive : IsPositive G 1 T)
31 (hnoclash : IsNoClash G 1 T)
32 (hwidth : HasWidthAtMost T d)
33 (hnonempty : HasNonemptySets T) :
34 IsPositive G 1 (copyTeachingSet T source target) ∧
35 IsNoClash G 1 (copyTeachingSet T source target) ∧
36 HasWidthAtMost (copyTeachingSet T source target) d ∧
37 HasNonemptySets (copyTeachingSet T source target)
38
39end Lax16.TwinReduction
