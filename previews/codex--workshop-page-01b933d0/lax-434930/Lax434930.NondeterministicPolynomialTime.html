      Definition

      A binary language AAA belongs to NP\mathrm{NP}NP if there are a verifier language V∈PV\in\mathrm{P}V∈P and a polynomial p∈N[X]p\in\mathbb{N}[X]p∈N[X] such that x∈Ax\in Ax∈A precisely when some binary certificate yyy with ∣y∣≤p(∣x∣)|y|\le p(|x|)∣y∣≤p(∣x∣) satisfies ⟨x,y⟩∈V\langle x,y\rangle\in V⟨x,y⟩∈V. The verifier is a single deterministic polynomial-time decider on the explicit pair encoding, and its running time is polynomial in the combined input and certificate lengths. The certificate bound depends only on the original input length. This is the standard certificate definition of NP.
