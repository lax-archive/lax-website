  2. defLax762056.MaxCut

    Maximum cuts

    For a graph FFF on an ordered vertex set, each edge is represented once, by its endpoints u<vu<vu<v. A cut is specified by a subset SSS of vertices; its size is the number of edges with exactly one endpoint in SSS. MaxCut⁡(F)\operatorname{MaxCut}(F)MaxCut(F) is the largest such size, with value zero for an edgeless graph.

  5. defLax762056.ColumnGraph

    Row and column graphs

    For a row set RRR and ccc columns, the graph has vertices (r,j,s)∈R×{0,…,c−1}×{0,1}(r,j,s)\in R\times\{0,\ldots,c-1\}\times\{0,1\}(r,j,s)∈R×{0,…,c−1}×{0,1}. Each column induces a complete bipartite graph between its two sides. Within a row, every vertex is adjacent to both vertices in each consecutive column. There are no other edges.

    The Bonnet–Chang reduction

    Order the vertices of FFF as 0,…,n−10,\ldots,n-10,…,n−1. For every edge uvuvuv with u<vu<vu<v, reserve rows (uv,0)(uv,0)(uv,0) and (uv,1)(uv,1)(uv,1) in an intermediate graph with 2n−12n-12n−1 columns. Keep only columns from 2u2u2u through 2v2v2v. In row (uv,t)(uv,t)(uv,t) keep only side ttt at column 2u2u2u and side 1−t1-t1−t at column 2v2v2v; keep both sides at every intervening column. The resulting induced subgraph is GFG_FGF​.

  14. lem✓Lax762056.IndependenceIdentity

    The independence number records the maximum cut

    For every finite simple graph FFF, α(GF)=MaxCut⁡(F)+b(F)\alpha(G_F)=\operatorname{MaxCut}(F)+b(F)α(GF​)=MaxCut(F)+b(F). An independent set chooses at most one side in each column and so determines a cut of FFF (empty columns may be assigned either side). The two rows for an edge uvuvuv contribute at most 2(v−u)+12(v-u)+12(v−u)+1 vertices, and at most 2(v−u)2(v-u)2(v−u) when its endpoints lie on the same side. Conversely, every cut realizes the sum of these bounds.
