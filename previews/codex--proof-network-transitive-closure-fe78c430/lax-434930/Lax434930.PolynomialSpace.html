      Definition

      A binary language belongs to PSPACE\mathrm{PSPACE}PSPACE if one deterministic Turing machine decides membership using at most p(n)p(n)p(n) work cells on inputs of length nnn, for some polynomial p∈N[X]p\in\mathbb{N}[X]p∈N[X]. The input tape is read-only and excluded from work space, and the machine always halts.
