Tight Inapproximability of Max Independent Set in Triangle-Free Graphs

lax-47·formalized by Édouard Bonnet @EdouardBonnet·created 2026-08-07·GitHub @e8e3010·Lean v4.30.0 · mathlib c5ea00351c28

Abstract

This submission formalizes the main inapproximability theorem of Tight Inapproximability of Max Independent Set in Triangle-Free Graphs. Assuming Håstad's promise hardness of Max Independent Set, it proves that, for every constant ε>0\varepsilon>0ε>0, a polynomial-time N1/2−εN^{1/2-\varepsilon}N1/2−ε-approximation algorithm on NNN-vertex triangle-free graphs implies NP⊆BPPNP\subseteq BPPNP⊆BPP.

The reduction blows each vertex of an nnn-vertex graph up into nnn vertices, samples the blow-up edges independently, and resamples the edges of present triangles. The formalization proves triangle-freeness, completeness, the fixed-set soundness estimate, the finite-seed probability bound, and the final gap arithmetic. The infinite product table occurs only in the probabilistic analysis; the program itself reads a polynomially bounded finite family of uniform bits.

Polynomial time, NPNPNP, and BPPBPPBPP use a bounded interpreter for fixed finite binary multi-stack Turing machines. Every semantic answer is the output of that interpreter. The composed triangle-removal program has a fixed recursive evaluator whose state and operation count are produced by the same execution, and the proof derives explicit polynomial bounds for the reduction, the approximation-machine call, decoding, threshold arithmetic, and random bits.
