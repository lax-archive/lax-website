      Definition

      A word RAM is a random access machine whose cells hold words: natural numbers below 2w2 ^ w2w, for a word length www that is a parameter of the model. It has a memory of 2w2 ^ w2w cells, addressed by number, and no other storage. Input arrives on a read-only input tape and output is written on a write-only output tape. A program is a finite sequence of instructions, executed in order unless a jump instruction changes the program counter. Every instruction names the cells it works on: it sets a cell to a literal; it reads or writes a cell through the address held in another cell; it sets a cell to the sum, the difference, the product, the quotient, the bitwise conjunction or the left shift of two cells, or to the bitwise complement of one; it jumps unconditionally or if a cell is zero; it halts; or it reads the next input number into a cell or writes a cell to the output tape.

      All arithmetic is arithmetic on words: every value the machine produces is taken modulo 2w2 ^ w2w, and every address is taken modulo 2w2 ^ w2w. Subtraction is truncated at zero rather than wrapping. Division is integer division, with x/0=0x / 0 = 0x/0=0.

      The machine starts with all memory cells zero, the whole input word on the input tape and the output tape empty; it halts having written the output word. The running time is the number of instructions executed, each costing one time unit.

      263/-- One step of the machine at word length `w`: fetch the instruction
      264the program counter points at and execute it. The result is `none` if
      265the machine has halted, which also happens when the program counter has
      266run past the program. -/

      268 p[s.pc]?.bind fun i => i.effect w s

      270/-- The state after `t` steps at word length `w`, or `none` if the
      271machine halts before executing `t` instructions. -/

      273 | 0, s => some s
      274 | t + 1, s => (step w p s).bind (run w p t)

      288 ∃ s : State, run w p t (initState x) = some s ∧ step w p s = none ∧ s.out = y
