      Definition

      A binary language belongs to NPSPACE\mathrm{NPSPACE}NPSPACE if one nondeterministic Turing machine decides membership using at most p(n)p(n)p(n) work cells on every branch on inputs of length nnn, for some polynomial p∈N[X]p\in\mathbb{N}[X]p∈N[X]. All branches halt; at least one accepts precisely when the input belongs to the language. The input tape is read-only and excluded from work space.
