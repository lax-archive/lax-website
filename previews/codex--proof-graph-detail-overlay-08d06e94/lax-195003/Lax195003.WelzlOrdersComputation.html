      Theorem

      Let C be a graph class whose members have neighborhood complexity at most c · k, for one constant c ≥ 1 shared by the class. There is a randomized algorithm which, given an n-vertex graph G in C and c, runs in O((n+m)logn)O((n+m) log n)O((n+m)logn) time and, with probability at least 2/3, returns a total order of the vertices with crossing number at most 12c² log² n.

      This is Theorem 1.3 of Dreier and Kuske, Near-Linear Time Computation of Welzl Orders on Graphs with Linear Neighborhood Complexity (2026).

      25in this submission, together with the per-graph predicate used below. They

      27and require the genuinely linear bound `π_G(k) ≤ c · k`. The graph is
