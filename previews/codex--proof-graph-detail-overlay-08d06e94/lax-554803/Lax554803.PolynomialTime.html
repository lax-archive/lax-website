      Definition

      A language of finite binary strings belongs to P\mathrm{P}P if a deterministic Turing machine decides membership in that language in polynomial time. Precisely, there are a single machine and a polynomial p∈N[X]p \in \mathbb{N}[X]p∈N[X] such that, on every input www, the machine halts within p(∣w∣)p(|w|)p(∣w∣) steps and returns the bit 111 if www belongs to the language and 000 otherwise.

      The definition uses mathlib's deterministic stack machines, the identity encoding of binary strings, and a singleton Boolean output. Time counts transitions of fixed finite instruction blocks. We also prove equivalence with elementary single-tape machines.
