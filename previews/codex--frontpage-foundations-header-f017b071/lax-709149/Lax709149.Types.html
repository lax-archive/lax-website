      Definition

      The types of Section C.5 of Transducers (Definition C.5.1) are the expressions built from the unit type 1\mathbb{1}1, which has the unique element 111, by the product A×BA \times BA×B, the co-product A+BA + BA+B and the list type A∗A^*A∗. Every element of a type has a string representation over a fixed alphabet with eight letters

      ()[],1LR,( \quad ) \quad [ \quad ] \quad , \quad 1 \quad L \quad R,()[],1LR,

      defined by induction on the type: the unique element of 1\mathbb{1}1 is 111, an element of A+BA + BA+B is L aL\,aLa or R bR\,bRb, a pair is (a,b)(a, b)(a,b), and a list is [a1,…,an][a_1, \ldots, a_n][a1​,…,an​]. Through this representation, type-to-type functions can be computed by string-to-string transducers (Definition C.5.2).

      30/-- A type: built from the unit type by product, co-product and list. -/
      31inductive Ty : Type
      32 | one : Ty
      33 | prod : Ty → Ty → Ty
      34 | sum : Ty → Ty → Ty
      35 | list : Ty → Ty
      36 deriving DecidableEq

      38/-- The set of elements of a type. -/
      39def Ty.Elt : Ty → Type
      40 | .one => Unit
      41 | .prod A B => A.Elt × B.Elt
      42 | .sum A B => A.Elt ⊕ B.Elt
      43 | .list A => List A.Elt
      44
      45/-- The alphabet with eight letters `(`, `)`, `[`, `]`, `,`, `1`, `L`, `R`. -/
      46inductive Sym8 : Type
      47 | lpar | rpar | lbrack | rbrack | comma | one | left | right
      48 deriving DecidableEq, Fintype
      49
      50/-- The entries of a list representation, separated by commas. -/
      51def joinSep : List (List Sym8) → List Sym8
      52 | [] => []
      53 | [x] => x
      54 | x :: xs => x ++ Sym8.comma :: joinSep xs
      55
      56/-- The string representation of an element: `1` for the unit, `L a` and `R b` for
      57the co-product, `(a,b)` for a pair, `[a₁,…,aₙ]` for a list. -/
      58def Ty.repr : (t : Ty) → t.Elt → List Sym8
      59 | .one, _ => [Sym8.one]
      60 | .prod A B, x => Sym8.lpar :: (A.repr x.1 ++ Sym8.comma :: (B.repr x.2 ++ [Sym8.rpar]))
      61 | .sum A B, x => Sum.elim (fun a => Sym8.left :: A.repr a) (fun b => Sym8.right :: B.repr b) x
      62 | .list A, l => Sym8.lbrack :: (joinSep (l.map A.repr) ++ [Sym8.rbrack])
