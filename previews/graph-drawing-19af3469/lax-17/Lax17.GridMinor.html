      Definition

      A graph contains a square grid minor of order ggg when the canonical g×gg\times gg×g square grid is a minor of it.

      Because graph-minor containment is invariant under relabelling, choosing the canonical coordinate grid loses no generality.

      Lean source view on GitHub
