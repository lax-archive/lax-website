      Definition

      A binary language belongs to NL\mathrm{NL}NL if a nondeterministic Turing machine decides membership using O(log⁡n)O(\log n)O(logn) work space and a separate read-only input tape. Every branch halts and respects the space bound; membership means that at least one branch accepts. The bound is c⌊log⁡2(n+2)⌋c\lfloor\log_2(n+2)\rfloorc⌊log2​(n+2)⌋ for one positive constant ccc.
