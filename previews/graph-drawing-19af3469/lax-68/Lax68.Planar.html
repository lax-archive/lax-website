      Definition

      A graph is planar here when it has a crossing-free straight-line drawing in the real plane. For finite simple graphs, this agrees with the usual notion of planarity. The drawing certificate is supplied by a separate concept.

      Lean source view on GitHub

      6title: Planar graphs

      9A graph is planar here when it has a crossing-free straight-line drawing in
      10the real plane. For finite simple graphs, this agrees with the usual notion
      11of planarity. The drawing certificate is supplied by a separate concept.
      12-/

      14set_option autoImplicit false

      16namespace Lax68.Planar
      17
      18/-- Existence of a crossing-free straight-line drawing in the real plane. -/
      19def IsPlanar {V : Type*} (G : SimpleGraph V) : Prop :=
      20 StraightLineDrawings.HasStraightLineDrawing G
      21
      22def IsPlanarByExcludedMinors {V : Type*} (G : SimpleGraph V) : Prop :=
      23 ¬GraphMinors.IsMinor GraphMinors.K5 G ∧
      24 ¬GraphMinors.IsMinor GraphMinors.K33 G
