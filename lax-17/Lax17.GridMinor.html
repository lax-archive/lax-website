Lax17.GridMinor

Square grid minors

concepts/Lax17/GridMinor.lean · lax-17

nothing to prove

Concept map

Definition

A graph contains a square grid minor of order (g) when the canonical (g\times g) square grid is a minor of it.

Because graph-minor containment is invariant under relabelling, choosing the canonical coordinate grid loses no generality.
