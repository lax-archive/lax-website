      Definition

      A k-division of a matrix partitions its rows into k sets of consecutive rows and its columns into k sets of consecutive columns; its k² cells are the intersections of a row set with a column set. A matrix has a k-grid minor if it has a k-division with at least one 1-entry in each of its k² cells. The grid number of a matrix is the largest k such that it has a k-grid minor. The grid number of a graph G, denoted by gn(G), is the minimum, taken among all the adjacency matrices M of G, of the grid number of M.

      28/-- `M` has a `k`-grid minor: a division of the rows and of the columns into
      29`k` sets of consecutive indices such that every cell contains a 1-entry. -/
      30def HasGridMinor {n : ℕ} (M : Fin n → Fin n → Prop) (k : ℕ) : Prop :=
      31 ∃ r c : Fin (k + 1) → ℕ,
      32 StrictMono r ∧ r 0 = 0 ∧ r (Fin.last k) = n ∧
      33 StrictMono c ∧ c 0 = 0 ∧ c (Fin.last k) = n ∧
      34 ∀ i j : Fin k, ∃ a b : Fin n,
      35 r i.castSucc ≤ a.val ∧ a.val < r i.succ ∧
      36 c j.castSucc ≤ b.val ∧ b.val < c j.succ ∧ M a b
      37
      38/-- The grid number of a 0/1 matrix: the largest `k` such that it has a
      39`k`-grid minor. -/
      40noncomputable def matrixGridNumber {n : ℕ} (M : Fin n → Fin n → Prop) : ℕ :=
      41 sSup {k | HasGridMinor M k}
      42
      43/-- The adjacency matrix of `G` under the vertex ordering `σ`. -/
      44def adjacencyMatrix {V : Type} (G : SimpleGraph V) {n : ℕ} (σ : Fin n ≃ V) :
      45 Fin n → Fin n → Prop :=
      46 fun a b => G.Adj (σ a) (σ b)

      48/-- The grid number of a finite simple graph: the least grid number of one of
      49its adjacency matrices. -/
      50noncomputable def gridNumber {V : Type} [Fintype V] [DecidableEq V]
      51 (G : SimpleGraph V) : ℕ :=
      52 sInf {k | ∃ σ : Fin (Fintype.card V) ≃ V,
      53 matrixGridNumber (adjacencyMatrix G σ) = k}
