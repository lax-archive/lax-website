Description

Every large enough graph contains a clique on aaa vertices or an independent set on bbb vertices, derived from the multicolour Ramsey theorem for pairs of this submission.

Proof strategy

The graph form is the two-colour case of the multicolour statement, and this module derives it that way rather than reproving it, so that the archive records the derivation.

Apply Lax14.MulticolorRamsey.existsmonochromaticsetLax14.MulticolorRamsey.exists_monochromatic_setLax14.MulticolorRamsey.existsm​onochromatics​et with two colours and requested size maxabmax a bmaxab, and colour a pair of vertices by 000 when it is an edge of the graph and by 111 otherwise. The colouring is well defined on unordered pairs because adjacency is symmetric, which is what Sym2.liftSym2.liftSym2.lift requires. The resulting monochromatic set of size at least maxabmax a bmaxab is a clique when its colour is 000 and an independent set when its colour is 111, since Set.PairwiseSet.PairwiseSet.Pairwise in either case says exactly that distinct members are adjacent, respectively non-adjacent; maxmaxmax then supplies the requested bound aaa in the first branch and bbb in the second.

Attribution

Ramsey, On a problem of formal logic (Proc. London Math. Soc. 1930).
