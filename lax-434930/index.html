      Abstract

      We formalize the classical complexity classes L\mathrm{L}L, NL\mathrm{NL}NL, P\mathrm{P}P, NP\mathrm{NP}NP, coNL\mathrm{coNL}coNL, coNP\mathrm{coNP}coNP, PSPACE\mathrm{PSPACE}PSPACE, NPSPACE\mathrm{NPSPACE}NPSPACE, and EXPTIME\mathrm{EXPTIME}EXPTIME for languages of finite binary strings. P uses deterministic stack machines, identity encoding of binary inputs, and singleton Boolean outputs. NP uses polynomially bounded certificates and polynomial-time verification. We prove equivalence with finite single-tape machines and closure under complement. EXPTIME uses these single-tape machines. The space classes use finite Turing machines with a bounded, read-only input tape and a separate work tape, whose space is bounded on every computation branch. We prove the full chain through L⊆NL\mathrm{L}\subseteq\mathrm{NL}L⊆NL, NL⊆P\mathrm{NL}\subseteq\mathrm PNL⊆P, P⊆NP\mathrm{P}\subseteq\mathrm{NP}P⊆NP, NP⊆PSPACE\mathrm{NP}\subseteq\mathrm{PSPACE}NP⊆PSPACE, PSPACE=NPSPACE\mathrm{PSPACE}=\mathrm{NPSPACE}PSPACE=NPSPACE (Savitch's theorem), and NPSPACE⊆EXPTIME\mathrm{NPSPACE}\subseteq\mathrm{EXPTIME}NPSPACE⊆EXPTIME. We also state P≠NP\mathrm{P}\ne\mathrm{NP}P=NP as an open question.
