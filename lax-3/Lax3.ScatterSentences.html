Definition

A set of vertices is r-scattered if its members have pairwise distance larger than r. A scatter sentence asserts that a distinguished r-scattered set of the vertices satisfying a one-variable formula β has at least t elements. Which scattered set is distinguished is the content of a scatter choice: for each graph, radius and vertex set it names a number that is the size of some inclusion-wise maximal r-scattered subset of that set. Two choices are given — the maximum size of a scattered subset, and the size of the set the greedy process produces when it runs through the vertices in order and takes every vertex it can.

The locality theorem of Lax3.LocalityLax3.LocalityLax3.Locality rewrites a formula into a boolean combination of local formulas and scatter sentences. Scatter sentences of distance rank (k, q) are those whose parameters obey the source's schedule: at most k + q witnesses, a local β of distance rank (k+i, q−i) for some 1 ≤ i ≤ q, and a radius between 4ρ⁻(k+i, q−i) and 9^(k+i)ρ⁻(k+i, q−i). The lower bound makes β semantically (r/4)-local, which is what the proof of the theorem consumes; the upper bound keeps the radius below ρ⁻(k, q), which is what keeps the rank from growing.

This is §2.1 of the source note (arXiv:2606.23180), specialized to the finite colored graphs of Lax3.ColoredGraphsLax3.ColoredGraphsLax3.ColoredGraphs.

13A set of vertices is *r*-scattered if its members have pairwise
14distance larger than *r*. A *scatter sentence* asserts that a
15distinguished *r*-scattered set of the vertices satisfying a
16one-variable formula β has at least *t* elements. Which scattered set
17is distinguished is the content of a *scatter choice*: for each graph,
18radius and vertex set it names a number that is the size of *some*
19inclusion-wise maximal *r*-scattered subset of that set. Two choices
20are given — the maximum size of a scattered subset, and the size of the
21set the greedy process produces when it runs through the vertices in
22order and takes every vertex it can.
23
24The locality theorem of `Lax3.Locality` rewrites a formula into a
25boolean combination of local formulas and scatter sentences. Scatter
26sentences of distance rank (*k*, *q*) are those whose parameters obey
27the source's schedule: at most *k* + *q* witnesses, a local β of
28distance rank (*k*+*i*, *q*−*i*) for some 1 ≤ *i* ≤ *q*, and a radius
29between 4ρ⁻(*k*+*i*, *q*−*i*) and 9^(*k*+*i*)ρ⁻(*k*+*i*, *q*−*i*). The
30lower bound makes β semantically (*r*/4)-local, which is what the proof
31of the theorem consumes; the upper bound keeps the radius below
32ρ⁻(*k*, *q*), which is what keeps the rank from growing.

37# Formalization notes
38
39The scatter choice is per graph, radius and vertex set; the source's is
40per structure, radius and formula β. The two agree wherever a scatter
41sentence is evaluated, since the vertex set involved is always
42{*a* : β(*a*) holds}, and the coarser form is strictly stronger: it
43forces the same value for two formulas defining the same set, and it is
44uniform in the coloring, so a scatter value cannot change when colors
45are added that β does not mention. Both are properties the algorithm
46needs and neither is available from the source's form. The dependence
47on the graph is genuine and stays.
48
49"*r*-scattered" is Lax12's `DistIndependent`: a set is distance-*r*
50independent in `G` when every walk between two distinct members is
51longer than *r*, which is the source's "pairwise distance larger than
52*r*" in the Gaifman graph, since the Gaifman graph of a colored graph
53is the graph. It is used as it stands and not restated here.
54Inclusion-wise maximality is mathlib's `Maximal`, over the property of
55being a scattered subset of the given set.
56
57Over `Fin n` every vertex set is finite, so the source's value ∞ — for
58structures with arbitrarily large scattered subsets — cannot arise and
59is not carried; `ScatterChoice.size` is ℕ-valued.
60
61`greedyChoice` is the source's greedy process in the canonical order on
62`Fin n`, phrased as the recursion it is: a vertex is selected exactly
63when it belongs to the set and no *earlier selected* vertex is within
64distance *r* of it. Running the process along a list and reading off
65its result gives the same set, one step of the recursion at a time; the
66recursion is what the proofs use and what the machine implements.
67Both choices are `noncomputable` in the Lean sense, because both take
68the cardinality of a set. "Computable" in the source's sense — and the
69sense the algorithm needs — means computed by the RAM program of the
70headline theorem, which runs exactly this `Fin`-order greedy over the
71tabulated truth values of β; it has nothing to do with code extraction
72from these definitions.
73
74The distance rank of a scatter sentence is the source's condition
75(2)/(eq:scatter-radius) verbatim, with the bound *t* ≤ *k* + *q* stated
76alongside the radius window rather than in the surrounding prose.
77Nothing here requires *q* ≥ 1: for *q* = 0 the condition 1 ≤ *i* ≤ *q*
78is unsatisfiable, so no scatter sentence has distance rank (*k*, 0),
79which is the source's convention made into a fact.
80-/

86/-- A choice of scatter values: for every graph `G`, radius `r` and
87vertex set `X`, a number `size G r X` which is the cardinality of some
88inclusion-wise maximal `r`-scattered subset of `X`. This is the
89source's "fix arbitrarily and once and for all a value `s`", made a
90parameter: every statement about scatter sentences holds for every
91choice. -/
92structure ScatterChoice where
93 /-- The chosen scatter value of a graph, radius and vertex set. -/
94 size : ∀ {n : ℕ}, SimpleGraph (Fin n) → ℕ → Set (Fin n) → ℕ
95 /-- The chosen value is realized by an inclusion-wise maximal
96 `r`-scattered subset of `X`. -/
97 spec : ∀ {n : ℕ} (G : SimpleGraph (Fin n)) (r : ℕ) (X : Set (Fin n)),
98 ∃ S : Set (Fin n), S ⊆ X ∧
99 Maximal (fun T => T ⊆ X ∧ DistIndependent G r T) S ∧ S.ncard = size G r X
100
101/-- The source's "maximum size" choice: the largest cardinality of an
102`r`-scattered subset of `X`. A subset of that size is inclusion-wise
103maximal, since no scattered set can properly contain it. -/
104noncomputable def maxChoice : ScatterChoice where
105 size := fun {n} G r X =>
106 sSup {c | ∃ S : Set (Fin n), S ⊆ X ∧ DistIndependent G r S ∧ S.ncard = c}
107 spec := by
108 intro n G r X
109 set C : Set ℕ := {c | ∃ S : Set (Fin n), S ⊆ X ∧ DistIndependent G r S ∧ S.ncard = c}
110 have hne : C.Nonempty :=
111 ⟨0, ∅, Set.empty_subset _, Set.pairwise_empty _, Set.ncard_empty _⟩
112 have hbdd : BddAbove C := by
113 refine ⟨n, ?_⟩
114 rintro c ⟨S, -, -, rfl⟩
115 calc S.ncard ≤ (Set.univ : Set (Fin n)).ncard :=
116 Set.ncard_le_ncard (Set.subset_univ S) Set.finite_univ
117 _ = n := by simp
118 obtain ⟨S, hSX, hSind, hScard⟩ := Nat.sSup_mem hne hbdd
119 refine ⟨S, hSX, ⟨⟨hSX, hSind⟩, ?_⟩, hScard⟩
120 rintro T ⟨hTX, hTind⟩ hST
121 have hT : T.ncard ∈ C := ⟨T, hTX, hTind, rfl⟩
122 have hle : T.ncard ≤ S.ncard := hScard ▸ le_csSup hbdd hT
123 exact (Set.eq_of_subset_of_ncard_le hST hle).symm.subset

125/-- The greedy process of the source, in the canonical order on
126`Fin n`: the vertex `v` is selected exactly when it lies in `X` and no
127earlier selected vertex is within distance `r` of it. -/
128def GreedyMem {n : ℕ} (G : SimpleGraph (Fin n)) (r : ℕ) (X : Set (Fin n)) (v : Fin n) : Prop :=
129 v ∈ X ∧ ∀ u : Fin n, u < v → GreedyMem G r X u → ¬ WithinDist G r u v
130termination_by v.val
131
132/-- The set the greedy process selects. -/
133def greedySet {n : ℕ} (G : SimpleGraph (Fin n)) (r : ℕ) (X : Set (Fin n)) : Set (Fin n) :=
134 {v | GreedyMem G r X v}

136/-- The source's "greedy choice": the size of the set produced by the
137greedy process on `X` in the canonical order on `Fin n`. That set is
138scattered because a selected vertex is far from every earlier selected
139one, and inclusion-wise maximal because a vertex of `X` it passed over
140is within distance `r` of a selected one. -/
141noncomputable def greedyChoice : ScatterChoice where
142 size := fun {_n} G r X => (greedySet G r X).ncard
143 spec := by
144 intro n G r X
145 have hmem : ∀ v : Fin n, v ∈ greedySet G r X ↔
146 v ∈ X ∧ ∀ u : Fin n, u < v → u ∈ greedySet G r X → ¬ WithinDist G r u v := by
147 intro v
148 rw [greedySet, Set.mem_setOf_eq, GreedyMem]
149 rfl
150 have hsub : greedySet G r X ⊆ X := fun v hv => ((hmem v).1 hv).1
151 have hind : DistIndependent G r (greedySet G r X) := by
152 intro a ha b hb hab p
153 rcases lt_or_gt_of_ne hab with h | h
154 · by_contra hlen
155 exact ((hmem b).1 hb).2 a h ha ⟨p, by omega⟩
156 · by_contra hlen
157 refine ((hmem a).1 ha).2 b h hb ⟨p.reverse, ?_⟩
158 rw [SimpleGraph.Walk.length_reverse]
159 omega
160 refine ⟨greedySet G r X, hsub, ⟨⟨hsub, hind⟩, ?_⟩, rfl⟩
161 rintro T ⟨hTX, hTind⟩ hST v hvT
162 by_contra hvS
163 rw [hmem] at hvS
164 push Not at hvS
165 obtain ⟨u, hlt, huS, w, hw⟩ := hvS (hTX hvT)
166 exact absurd (hTind (hST huS) hvT (ne_of_lt hlt) w) (by omega)

168/-- A scatter sentence: there is an `r`-scattered set of `t` vertices
169satisfying the one-variable formula `β`, in the sense fixed by a
170scatter choice. -/
171structure ScatterSentence (L : ℕ) where
172 /-- The radius at which the witnesses are scattered. -/
173 r : ℕ
174 /-- The one-variable formula the witnesses satisfy. -/
175 β : DistFO L 1
176 /-- The number of witnesses demanded. -/
177 t : ℕ
178
179variable {L n : ℕ}
180
181/-- The scatter sentence holds in the colored graph `(G, col)` when the
182chosen scatter value of the set defined by `β`, at radius `r`, is at
183least `t`. -/
184def ScatterSentence.Sat (choice : ScatterChoice) (G : SimpleGraph (Fin n))
185 (col : Coloring n L) (σ : ScatterSentence L) : Prop :=
186 σ.t ≤ choice.size G σ.r {a | DistFO.Sat G col (fun _ => a) σ.β}
187
188/-- The scatter sentence has distance rank `(k, q)`: it demands at most
189`k + q` witnesses, and for some `1 ≤ i ≤ q` its formula `β` is local of
190distance rank `(k + i, q - i)` and its radius lies in the source's
191window `4ρ⁻(k + i, q - i) ≤ r ≤ 9 ^ (k + i) · ρ⁻(k + i, q - i)`. -/
192def ScatterSentence.DRank (k q : ℕ) (σ : ScatterSentence L) : Prop :=
193 σ.t ≤ k + q ∧ ∃ i, 1 ≤ i ∧ i ≤ q ∧ DistFO.IsLocal σ.β ∧
194 DistFO.DRank (k + i) (q - i) σ.β ∧
195 4 * rhoMinus (k + i) (q - i) ≤ σ.r ∧ σ.r ≤ 9 ^ (k + i) * rhoMinus (k + i) (q - i)
196
197end Lax3.ScatterSentences
