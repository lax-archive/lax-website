Tight Inapproximability of Max Independent Set in Triangle-Free Graphs

      Abstract

      Unless NP⊆BPPNP\subseteq BPPNP⊆BPP, for every constant ε>0\varepsilon>0ε>0, Max Independent Set on NNN-vertex triangle-free graphs admits no polynomial-time N1/2−εN^{1/2-\varepsilon}N1/2−ε-approximation algorithm. This is the main inapproximability theorem of Tight Inapproximability of Max Independent Set in Triangle-Free Graphs. Its proof uses Håstad's general-graph promise-gap hardness theorem as an unproven axiom.

      The reduction blows each vertex of an nnn-vertex graph up into nnn vertices, samples the blow-up edges independently, and resamples the edges of present triangles. The formalization proves triangle-freeness, completeness, the fixed-set soundness estimate, the finite-seed probability bound, and the final gap arithmetic. The infinite product table occurs only in the probabilistic analysis; the program itself reads a polynomially bounded finite family of uniform bits.

      Polynomial time is certified by a finite Turing machine. The proof derives explicit polynomial bounds for the reduction, the approximation-machine call, decoding, threshold arithmetic, and the number of random bits.
