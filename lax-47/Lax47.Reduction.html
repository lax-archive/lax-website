Lax47.Reduction

Reduction certificate for triangle-free Max Independent Set

concepts/Lax47/Reduction.lean · lax-47

Concept map

Definition

This concept isolates the mathematical and running-time facts supplied by the paper's randomized reduction. An nnn-vertex graph is sent, using a lazily read table of independent Boolean samples, to a graph on the n×nn\times nn×n blow-up of its vertices. The Moser–Tardos run is stopped after a polynomial cutoff; on a cutoff failure the output is the edgeless graph. A certificate requires that every output is triangle-free, its independence number is always at least nnn times that of the input, with probability at least two thirds it is at most a constant times α(H)nlog⁡n\alpha(H)n\log nα(H)nlogn, and its number of computation steps has a uniform polynomial bound.

The formulation deliberately exposes exactly what the final promise-gap argument consumes. The proof package constructs this certificate using the Moser–Tardos and Haeupler–Saha–Srinivasan theorems.

34/-- Vertices of the complete $n$-fold blow-up. -/
35abbrev BlowupVertex (n : ℕ) := Fin n × Fin n
36
37/-- Edge variables used by the resampling construction. -/
38abbrev EdgeVariable (n : ℕ) := Sym2 (BlowupVertex n)
39
40/-- The infinite table of Boolean samples read lazily by Moser--Tardos. -/
41abbrev SampleTable (n : ℕ) :=
42 ResamplingTable (fun _ : EdgeVariable n ↦ Bool)

44/--
45The probabilistic, combinatorial, and polynomial-step certificate delivered
46by the reduction in the paper.
47-/
48structure TriangleFreeReduction where
49 measure : ∀ n : ℕ, MeasureTheory.Measure (SampleTable n)
50 output : ∀ (n : ℕ), SimpleGraph (Fin n) →
51 SampleTable n → SimpleGraph (BlowupVertex n)
52 steps : ∀ (n : ℕ), SimpleGraph (Fin n) → SampleTable n → ℕ
53 probability : ∀ n, MeasureTheory.IsProbabilityMeasure (measure n)
54 triangleFree : ∀ (n : ℕ) (H : SimpleGraph (Fin n)) (table : SampleTable n),
55 (output n H table).CliqueFree 3
56 completeness : ∀ (n : ℕ) (H : SimpleGraph (Fin n)) (table : SampleTable n),
57 H.indepNum * n ≤ (output n H table).indepNum
58 soundnessConstant : ℝ
59 soundnessCutoff : ℕ
60 soundnessConstant_pos : 0 < soundnessConstant
61 soundness : ∀ (n : ℕ), soundnessCutoff ≤ n → ∀ H : SimpleGraph (Fin n),
62 measure n
63 {table | soundnessConstant * H.indepNum * n * Real.log n <
64 ((output n H table).indepNum : ℝ)} ≤ (1 : ℝ≥0∞) / 3
65 stepConstant : ℕ
66 stepExponent : ℕ
67 stepConstant_pos : 0 < stepConstant
68 stepBound : ∀ (n : ℕ) (H : SimpleGraph (Fin n)) (table : SampleTable n),
69 steps n H table ≤ stepConstant * (n + 1) ^ stepExponent
70
71/-- Existence of a reduction certificate with the paper's parameters. -/
72def HasTriangleFreeReduction : Prop :=
73 Nonempty TriangleFreeReduction
