      Natural Language Statement

      Theorem

      One finite RAM program reads the original weighted graph, clips negative weights, computes rounded copy counts, and constructs the adjacency matrix of the canonically numbered independent blow-up. Its output starts with the blow-up order and then gives the adjacency matrix in row-major order.

      Formalization notes

      The execution proof includes the actual unprefixed input reader, maximum scan, natural-number quotient for copy counts, owner-array construction, and every adjacency lookup. Copy owners agree exactly with the computable finite-sigma labeling used by the weighted algorithm. Time and sufficient word width are quadratic in the original order, blow-up order, and input rational height. This is the preprocessing program; the complete recursive RAM solver and its global quasipolynomial bound remain separate obligations.
