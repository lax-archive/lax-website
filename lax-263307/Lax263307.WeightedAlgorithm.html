      Natural Language Statement

      Definition

      Clip negative weights, round the remaining weights to copy multiplicities, and run the unweighted algorithm on the independent blow-up. Project the answer back to the original vertices and discard nonpositive-weight vertices. Empty and nonpositive instances return the empty set.

      30def labeling {n : ℕ} (copies : Fin n → ℕ) : Fin (∑ v, copies v) ≃ Vertex copies :=
      31 finSigmaFinEquiv.symm
      32
      33def numbered {n : ℕ} (G : SimpleGraph (Fin n)) (copies : Fin n → ℕ) :
      34 SimpleGraph (Fin (∑ v, copies v)) := (graph G copies).comap (labeling copies)
      35
      36instance {n : ℕ} (G : SimpleGraph (Fin n)) [DecidableRel G.Adj] (copies : Fin n → ℕ) :
      37 DecidableRel (numbered G copies).Adj := fun _ _ => inferInstanceAs (Decidable (G.Adj _ _))
      38
      39def solve {n : ℕ} (lp flow : List ℕ → List ℕ) (a K B : ℕ)
      40 (G : SimpleGraph (Fin n)) [DecidableRel G.Adj] (w : Fin n → ℚ) (ε : ℚ) : Finset (Fin n) :=
      41 let w' := positiveWeights w
      42 if n = 0 ∨ maximumWeight w' ≤ 0 then ∅
      43 else
      44 let copies' := copies w' ε
      45 let I := independentSet lp flow a K B (numbered G copies') (ε/2)
      46 discardNonpositive w (project (I.image (labeling copies')))

      Formalization notes

      The function takes fixed LP and flow solvers as arguments. Blow-up vertices are numbered by the finite-sigma equivalence. The complete correctness, RAM execution, and running-time guarantees are supplied by the proof of the main QPTAS theorem.
