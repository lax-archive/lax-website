      Natural Language Statement

      Definition

      The algorithm uses exhaustive search for small targets and projected round-or-cut search for larger targets. Recursive calls work on canonically labeled balanced parts. A descending target search selects the final set.

      26open RecursionDepth (depth)
      27open ComputedSeparators AlgorithmParameters

      29def attempt (lp flow : List ℕ → List ℕ) (a K B D : ℕ) (fuel : ℕ)
      30 {n : ℕ} (G : SimpleGraph (Fin n)) [DecidableRel G.Adj] (k : ℕ) : Option (Finset (Fin n)) :=
      31 if k ≤ cutoff a K B n D ∨ n ≤ 1 then findIndependentSet G k
      32 else if n < k then none
      33 else match fuel with
      34 | 0 => none
      35 | fuel + 1 => ProjectedOracle.search lp flow a K B D G k
      36 (fun C t => (attempt lp flow a K B D fuel (restriction G C) t).map
      37 (fun I => I.image (label C)))
      38termination_by fuel
      39
      40def solve {n : ℕ} (lp flow : List ℕ → List ℕ) (a K B D : ℕ)
      41 (G : SimpleGraph (Fin n)) [DecidableRel G.Adj] : Finset (Fin n) × ℕ :=
      42 TargetSearch.search (attempt lp flow a K B D (depth n) G) n
      43
      44def Correct {n : ℕ} (G : SimpleGraph (Fin n)) (k fuel D : ℕ) : Option (Finset (Fin n)) → Prop
      45 | some I => G.IsIndepSet (I : Set (Fin n)) ∧ (1 - 4*(1/(D:ℝ)))^fuel * (k:ℝ) ≤ I.card
      46 | none => ∀ J : Finset (Fin n), G.IsIndepSet (J : Set (Fin n)) → J.card < k
      47
      48def accuracyDenominator (n : ℕ) (ε : ℚ) : ℕ :=
      49 4 * (depth n + 1) * ⌈ε⁻¹⌉₊
      50
      51def independentSet {n : ℕ} (lp flow : List ℕ → List ℕ) (a K B : ℕ)
      52 (G : SimpleGraph (Fin n)) [DecidableRel G.Adj] (ε : ℚ) : Finset (Fin n) :=
      53 (solve lp flow a K B (accuracyDenominator n ε) G).1

      Formalization notes

      The fuel parameter bounds recursion depth. CorrectCorrectCorrect records the size guarantee for a returned independent set and the upper bound certified by failure. The accuracy denominator is 4(depth⁡(n)+1)⌈1/ε⌉4(\operatorname{depth}(n)+1)\lceil1/\varepsilon\rceil4(depth(n)+1)⌈1/ε⌉.
